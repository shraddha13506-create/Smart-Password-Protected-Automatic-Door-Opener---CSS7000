# About
Smart home automation has become increasingly popular due to its ability to improve security, convenience, and energy efficiency. One of the most common applications of home automation is an automatic door system.
This project presents a Smart Password-Protected Automatic Door Opener using an Arduino UNO. Unlike a basic automatic door that opens whenever a person is detected, this system requires the user to enter the correct password using four push buttons before the door can be opened. Once the password is verified, the ultrasonic sensor monitors the user's presence. The door remains open while the person is within the detection range and closes automatically after the person has completely passed through.
The project combines authentication, object detection, and automation into one system, making it more secure and suitable for homes, offices, laboratories, and restricted access areas.

# Objectives
Design a secure door access system using Arduino.
Authenticate the user through a predefined button sequence.
Detect a person's presence using an HC-SR04 ultrasonic sensor.
Automatically open and close the door using a servo motor.
Display system status on an LCD display.
Provide audio feedback using a buzzer.
Demonstrate a simple smart home security application.
